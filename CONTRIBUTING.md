# Contributing to LoopServe

Thanks for helping improve LoopServe.

## Development

```bash
npm install
npm run tauri dev
```

See the main [README](./README.md) for prerequisites and API overview.

## Pull requests

- Keep PRs focused on one change
- Match existing TypeScript / Rust style; avoid drive-by refactors
- Mention how you tested (platform + `tauri dev` / build)
- Update `CHANGELOG.md` for user-visible changes

## Releases

Maintainers: see [RELEASE.md](./RELEASE.md). Do not commit updater private keys.
